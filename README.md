# Город в 5 мирах

Онлайн-игра для форсайт-сессии «Сценарии развития территории и устойчивые решения». Участники играют с телефонов, ведущий управляет с ноутбука, на проекторе идёт общий экран.

Сайт лежит на **GitHub Pages**. Синхронизацию между телефонами делает **Google Таблица со скриптом (Apps Script)**: телефоны опрашивают её раз в 1,5–2 секунды. У GitHub Pages нет своего сервера, поэтому без такой связки онлайн-игра невозможна.

## Что внутри

```
docs/            сайт (публикуется через GitHub Pages)
  index.html
  config.js      ← сюда вставляется адрес скрипта
  assets/        код, стили, шрифты, QR-генератор (без внешних CDN)
gas/Code.gs      сервер игры для Google Apps Script
test/            локальная эмуляция сервера и автотест (для запуска не нужны)
```

## Запуск (≈10 минут)

### 1. Сервер в Google Таблице
1. Создайте новую Google Таблицу (например, «Форсайт — сервер»).
2. **Расширения → Apps Script**. Удалите всё в `Code.gs` и вставьте содержимое файла `gas/Code.gs`.
3. В начале файла поменяйте `HOST_PIN = '2040'` на свой PIN.
4. Выберите функцию `setup` и нажмите **Выполнить**. Разрешите доступ к таблице: «Дополнительные настройки» → «Перейти на страницу…».
5. **Развернуть → Новое развертывание → тип «Веб-приложение»**:
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
6. Скопируйте URL, который заканчивается на `/exec`.

> Если меняете `Code.gs` позже: **Развернуть → Управление развертываниями → ✏️ → Версия: новая**. Иначе будет работать старая версия.

### 2. Сайт на GitHub
1. Создайте публичный репозиторий и загрузите в него все файлы (Add file → Upload files).
2. В `docs/config.js` вставьте URL из шага 1.6 в `API_URL`.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

### 3. Ссылки на игру
| Кто | Ссылка |
|---|---|
| Игроки | `https://<логин>.github.io/<репозиторий>/` (QR показывается на проекторе) |
| Проектор | тот же адрес + `#screen` |
| Ведущий | тот же адрес + `#host` (нужен PIN) |
| Кураторы | тот же адрес + `#curator` (нужен PIN) |

## Ход игры

| Этап | Что делают | Время |
|---|---|---|
| Заставка | 4 слайда о форсайте на фоне анимации: случайные точки-сигналы → тренды → 5 миров → устойчивые решения. Ведущий листает их с пульта, а на пульте видна подсказка, что рассказывать | 8–10 мин |
| Сбор | Сканируют QR, вводят имя | 3 мин |
| Сигналы | Каждый присылает до 2 факторов будущего и сам относит их к типу: тренд, слабый сигнал, драйвер или джокер. На проекторе — стена сигналов по типам | 4 мин |
| Факторы | Каждый оценивает 8 факторов по влиянию и неопределённости (1–5). На проекторе строится карта факторов, правый верхний угол — критические неопределённости. Затем ведущий показывает оси нашей матрицы | 4 мин |
| Команды | Игроки выбирают команду 1–5 сами (до 4 человек) или ведущий раздаёт кнопкой | 2 мин |
| Миры | Миры A–E раздаются командам **случайно**. Команда придумывает название и последствия для жителей, бизнеса и власти, а также **ранние признаки** своего мира. На проекторе собирается сценарная матрица | 8 мин |
| Карта | Команда ставит 5 из 15 проектов на карту. **Место важно:** неудачное размещение (завод в лесу, жильё у комбината, жильё в пойме…) даёт штраф, удачное — бонус. Объяснение команда видит сразу | 10 мин |
| Наложение | Пять карт складываются в одну; проекты, которые выбрали 3+ команды, отмечаются как кандидаты в устойчивые решения | 4 мин |
| Аукцион | 100 монет на команду, закрытые ставки, 30–40 с на лот. Остаток монет сгорает | 10 мин |
| Судьба | Колесо выбирает наступивший мир. Очки = отдача проекта в этом мире + штраф или бонус за место | 3 мин |
| Шок | Карта-событие, очки пересчитываются, команды пишут, что изменили бы | 4 мин |
| Итоги | Две награды: лучший результат и самая устойчивая стратегия. На пульте — вопросы для рефлексии | 5 мин |

## Содержание
Город, слайды заставки, сигналы, факторы, миры, проекты и карты-шоки — в `docs/assets/content.js`. Таблица отдачи проектов в каждом мире, штрафы и бонусы за размещение и эффекты шоков — в `gas/Code.gs` (только на сервере, чтобы игроки не подсмотрели её в коде страницы). Все данные учебные, город вымышленный.

## Обновление до новой версии
1. В Apps Script замените весь код в `Code.gs` новым, верните свой PIN и сохраните (`Ctrl + S`).
2. **Развернуть → Управление развертываниями → ✏️ (карандаш) → Версия: «Новая версия» → Развернуть.** Адрес `/exec` останется прежним.
3. В GitHub загрузите новые файлы из папки `docs` с заменой. Свой `docs/config.js` не трогайте.
4. Старое состояние игры сбросится само при первом открытии.

## Перед занятием обязательно
- **Репетиция с командой (7 телефонов, 5 минут).** Пройдите все этапы. Затем на пульте: «Сброс игры → Полный сброс».
- **Проверьте связь в аудитории**: откройте сайт с Wi-Fi ВШЭ и с мобильного интернета. Сайт и Google-скрипт должны открываться.
- Если появляется ошибка «Сервер занят», увеличьте `POLL_PLAYER_MS` в `docs/config.js` до 3000.
